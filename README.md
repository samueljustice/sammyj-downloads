# Sammy J's plug-in downloads

Installers for Sammy J's paid plug-ins, by Samuel Justice. There is no source code here.

- **Installers** are on the [releases page](https://github.com/samueljustice/sammyj-downloads/releases),
  tagged `<product>-v<version>` (for example `body-language-v1.0.0`). Pre-releases are beta builds.
- **Update information** for each product is a small JSON file served from this repository's web
  address, for example <https://samueljustice.github.io/sammyj-downloads/body-language.json>. The
  plug-ins read it at most once a day to see whether a newer version exists.

Everything here is written by each product's release workflow; nothing is edited by hand.

The free plug-ins are at <https://samueljustice.github.io/plugins/>.
