The manual

What it is for, what each control does, and what we most want to hear about: read the manual.

Installing

  • macOS: open the installer. It puts the AU, VST3 and, when it's included, the AAX for Pro Tools in the usual folders, for every user. It's signed and notarised by Apple.
  • Windows: run the installer. It puts the VST3 (and the AAX, when it's included) in Common Files. It isn't code-signed yet, so Windows may warn that it's from an unknown publisher: choose More info, then Run anyway.
  • A new test version installs over the old one. The plug-in tells you when a newer one is out.

Before you start

This is an unfinished test version. Each one works for 60 days from the day it was built; after that it passes the sound through untouched and says so in its window, and the newest version from this page carries on. Please don't pass the download on.
